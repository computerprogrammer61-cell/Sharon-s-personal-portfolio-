# 2090 Futuristic Portfolio — Digital Architect

A cinematic, responsive Digital Architect portfolio starter spanning software engineering, AI, automation and creative technology built with plain HTML, CSS and JavaScript. No build tools or package installation required.

## Preview locally
1. Download or clone this repository.
2. Open `index.html` in your browser.
3. For a local development server, use VS Code's Live Server extension.

## Personalize before publishing
The starter is branded as Sharon Abubakar (SA). Update the displayed name, initials, and `hello@example.com` email if you want to change the branding.

Update:
- The hero introduction and About section in `index.html`
- Project titles, descriptions and visuals in the Selected Work section
- Skills to reflect tools you actually use
- Email and social profile links in the footer
- The page title and meta description

The project cards currently contain visual concepts. Replace them with links and descriptions for your real work.

## Deploy with GitHub Pages
1. Create a GitHub repository.
2. Upload the contents of this folder to the repository root (make sure `index.html` is at the root).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select your main branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish your site.

## Customize
- Main styling, colors, layout and responsive behavior: `styles.css`
- Scroll reveals, pointer glow and mobile navigation: `script.js`
- Page content and sections: `index.html`

## Notes
- Google Fonts are loaded from Google Fonts, so the font styling requires an internet connection.
- The site is intentionally dependency-free and can be hosted as a static GitHub Pages site.
